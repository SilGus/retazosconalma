# Recursos visuales de la landing

Los quince espacios visuales de la primera versión están completos en WebP. Las escenas y mockups se generaron con ImageGen; el ejemplo modelo/plantilla y la galería se obtuvieron de los entregables normalizados para mostrar diseños reales del producto.

## Reglas de optimización

- Cada recurso se exportó al ancho máximo que realmente utiliza.
- La portada dispone de variantes móvil y escritorio.
- Todas las imágenes tienen `width`, `height` y texto alternativo en el HTML.
- Las imágenes secundarias utilizan carga diferida y decodificación asíncrona.
- Cada variante de portada pesa menos de 180 KB.
- No incluir texto comercial dentro de las imágenes.
- Los mockups generados no deben presentarse como trabajos de compradores reales.
